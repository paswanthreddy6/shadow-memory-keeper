# Judge Q&A
**Is the memory real?** Yes. Every capture calls Hindsight retain; answers use recall and reflect. Nothing is stored in the browser.
**Does it survive refresh?** Yes — memory lives in the Hindsight bank.
**Can it hallucinate decisions?** Reflect is instructed to use only retained memories; with no recalled memories SHADOW says evidence is insufficient.
**Where is the API key?** Server-side secret only; never sent to the browser or returned by any endpoint.
**Is the demo data real customers?** No — NovaCart is fictional and labelled as demo.
